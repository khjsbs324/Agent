홈페이지 레퍼런스 분석 4단계 가이드
====================================

1. 4단계의 목적
----------------

4단계에서는 각 홈페이지를 어떤 항목으로 나누어 분석할지 확정한다.
여기서 정한 기준은 모든 홈페이지에 동일하게 적용한다.

이 단계에서는 TXT의 문장 형식이나 구분선을 정하지 않는다.
그 내용은 다음 5단계에서 정한다.


2. 권장 분류 기준
-----------------

아래 7개 대분류를 기본안으로 권장한다.

1) 기본 정보
   - 홈페이지 또는 서비스 이름
   - URL
   - 업종 또는 분야
   - 주요 대상 사용자
   - 자료 출처

2) 디자인 스타일
   - 전체적인 분위기
   - 색상 사용
   - 글꼴과 글자 크기
   - 이미지와 그래픽 스타일
   - 여백과 화면 밀도
   - 애니메이션 또는 인터랙션

3) 화면 구성과 레이아웃
   - 첫 화면 구성
   - 헤더와 메뉴
   - 주요 콘텐츠 배치
   - 섹션 순서
   - 하단 영역 구성
   - 모바일 화면 대응 방식

4) 메뉴와 사용자 흐름
   - 주요 메뉴 구조
   - 사용자가 처음 보게 되는 정보
   - 주요 행동 버튼
   - 문의, 가입, 구매 등의 이동 과정
   - 사용자가 혼동할 수 있는 지점

5) 문구와 콘텐츠
   - 첫 화면의 핵심 문구
   - 서비스 설명 방식
   - 신뢰를 주는 내용
   - 후기, 사례 또는 수치 사용
   - 행동을 유도하는 문구

6) 주요 기능
   - 검색
   - 회원가입과 로그인
   - 문의 또는 상담 신청
   - 예약 또는 구매
   - 필터와 정렬
   - 기타 특징적인 기능

7) 평가와 활용
   - 잘된 점
   - 아쉬운 점
   - 참고할 부분
   - 그대로 적용하면 안 되는 부분
   - 적용 가능한 아이디어


3. 기준을 검토하는 방법
-----------------------

각 대분류에 대해 아래 세 가지 중 하나를 선택한다.

- 유지: 현재 항목을 그대로 사용한다.
- 수정: 항목 이름이나 세부 항목을 바꾼다.
- 제외: 전체 분석에서 사용하지 않는다.

새 항목이 필요하면 어느 대분류 아래에 추가할지도 함께 적는다.


4. 결정할 때 주의할 점
----------------------

- 모든 홈페이지에서 확인할 가치가 있는 항목만 공통 기준으로 사용한다.
- 서로 의미가 겹치는 항목은 하나로 합친다.
- 원본 자료에 없는 정보는 추정하지 않고 "확인 불가"로 표시한다.
- 라이브 홈페이지를 조사하지 않으면 디자인, 사용자 흐름, 최신 기능 중
  상당 부분이 "확인 불가"가 될 수 있다.
- 점수 평가는 별도 미확정 사항이므로 이 단계에서 자동으로 추가하지 않는다.
- 분석 항목의 중요도나 가중치도 별도로 결정하기 전에는 모두 동등하게 다룬다.


5. 가장 간단한 확정 방법
------------------------

수정할 내용이 없다면 아래 문장으로 확정할 수 있다.

"4단계 권장 분류 기준 7개를 그대로 사용한다."

수정하려면 아래 양식을 사용한다.

[4단계 결정]
1. 기본 정보: 유지 / 수정 / 제외
2. 디자인 스타일: 유지 / 수정 / 제외
3. 화면 구성과 레이아웃: 유지 / 수정 / 제외
4. 메뉴와 사용자 흐름: 유지 / 수정 / 제외
5. 문구와 콘텐츠: 유지 / 수정 / 제외
6. 주요 기능: 유지 / 수정 / 제외
7. 평가와 활용: 유지 / 수정 / 제외

[수정하거나 추가할 내용]
- 대분류:
- 변경할 세부 항목:
- 변경 이유:


6. 확정 후 진행되는 작업
------------------------

1) 확정된 분류 기준을 스킬 참조 문서에 반영한다.
2) 4단계가 미확정이라는 차단 문구를 해제한다.
3) 다음 단계에서 홈페이지별 TXT 작성 순서와 레코드 구분 방식을 정한다.
4) 5단계까지 확정된 후에 시험 실행 여부를 확인한다.
