[로컬 경로(Local Path)]
내 컴퓨터 안에서 특정 파일이나 폴더가 저장되어 있는 위치를 나타내는 주소


[로컬 저장소(Local Repository)]
내 컴퓨터에 만들어진 Git 저장소로, 프로젝트 파일과 그 파일의 변경 이력을 함께 관리하는 공간


[현재 브랜치(Current Branch)]
현재 내가 작업하고 있는 Git 브랜치로, 새로 커밋한 변경 이력이 저장되는 작업 기준점


[원격 저장소(Remote Repository)]
GitHub처럼 인터넷에 존재하는 Git 저장소로, 로컬 저장소의 변경 이력을 업로드하거나 다른 사람과 공유하는 공간


[연결 관계(Remote Connection)]
내 로컬 저장소가 어떤 원격 저장소와 연결되어 있고, 어느 브랜치와 데이터를 주고받는지 나타내는 설정 정보


[변경된 파일(Changed Files)]
마지막 커밋 이후 새로 추가되거나 수정되거나 삭제되어 아직 새로운 버전으로 저장되지 않은 파일
